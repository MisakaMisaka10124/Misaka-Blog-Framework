# 2026-11-22 更新日志

## v1.3.5 - 加载性能与稳定性优化

### 加载与响应优化

- 首页并行加载站点配置、文章索引和服务器显示配置，减少首屏等待时间。
- 文章详情接口可直接返回渲染后的 HTML，减少一次请求往返和响应体积。
- 缓存文章索引和访客 IP 国家代码；重复访问时不再重复写入统计文件。
- 启用 CSS 压缩，移除全站加载的第三方国旗样式表，并使用本地 Unicode 旗帜符号。
- 哈希静态资源长期缓存；首页 HTML 不缓存，可变图片短期缓存并允许重新验证。
- 代码高亮改用常用语言集合，降低后端加载开销。

### Bug 修复与完善

- 修复带触屏电脑因主指针检测导致自定义光标不跟随的问题。
- 移除服务启动时自动打开浏览器的行为，避免后台服务额外启动 GUI。
- 允许较大的 JSON 文章内容通过请求体解析器。
- 修正 README、前后端开发文档及部署文档中的版本、目录和搜索范围说明。
